## 2. 实际变更与代码基线

### 2.1 已实现工程（历史基线）

- common 唯一 Result/ErrorCode/BaseException；client 对外请求响应；model 内部 DO。
- application 专属 Command/Result/assembler，domain 无 Spring API，以构造器接收仓储。
- Aggregate 仅 Entity，实体创建 Value 和状态行为；领域服务通过聚合入口协同并保存完整聚合。
- 基础仓储继承 MyBatis-Plus CrudRepository，主聚合单表 JSON 快照，规则独立空表，无内存仓储或自定义 SQL。
- adaptor input 只处理协议/应用转换，output 直接接 app Command、转换第三方私有协议到 DO。
- start 显式装配其余七个运行模块；根版本集中、revision/Flatten、Logback 双模式。
- 四层入口动作/参数名、中文 Javadoc/作者、字段说明、120 行宽、编号分步流程；Maven validate 的 Checkstyle 门禁。
