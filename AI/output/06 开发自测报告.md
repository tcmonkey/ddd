- JDK 17、Spring Boot 3.x、Maven、JUnit 5；根工程为 `ddd`（`packaging=pom`）聚合工程。

## 3. 计划偏差与设计变更

按 SRC-010～SRC-020 收紧类名、Spring 注入方式、MyBatis-Plus/H2 持久化、仓储契约、中文 Javadoc 和 output adaptor，并将具体案例改为 `Ddd*` 中性占位符。基础仓储前期手动传入 Mapper 是误判，已参考 itineary 改为沿用父类自动注入；数据案例由两张表收敛为一张，领域实体以 JSON 快照保存。历史检查记录保留，但当前结论以 DT-013 为准。

## 6. 已知问题与技术债

- H2 仅用于本地可重复验证，重启后无数据；生产 MySQL 的连接配置、迁移脚本和数据库级唯一约束仍未提供。
- 未接入鉴权、可观测平台、真实规则来源或并发冲突重试策略。
- 单表 JSON 快照只用于最小模板演示；真实业务若需按实体记录检索、建立索引或承载大量历史，应重新设计关系表或专用存储。
- 后续命名规范将作为代码与 Skill 的共同约束继续收敛。
